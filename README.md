# inbody-hub
inBody Hub es una aplicación web para cargar reportes InBody en imágenes o PDF, extraer y revisar sus mediciones y consolidarlas en un historial por persona. Permite consultar exámenes y exportar los datos en CSV, conservando su identificación, fecha, modelo del equipo y valores registrados. Utiliza React, FastAPI, Pydantic y PostgreSQL. El desarrollo corre en local y el entorno QA ejecuta frontend, backend y base de datos efímera dentro de Hugging Face Spaces. La arquitectura de producción contempla Neon, Render y Vercel, con CDC hacia Databricks y archivado controlado de datos históricos.
